# Data Structures and Algorithms

This repository contains my coursework and laboratory implementations for the **Data Structures and Algorithms (DSA)** course. It includes practical implementations and exercises covering fundamental data structures, their operations, and algorithmic problem-solving techniques.

## Course Topics

The coursework covers a range of fundamental data structures and algorithms, including:

### Linear Data Structures

* **Arrays**
* **Singly Linked Lists**
* **Doubly Linked Lists**
* **Stacks**
* **Queues**

### Non-Linear Data Structures

* **Trees**
* **Binary Search Trees (BST)**
* Tree traversal techniques
* Tree insertion, deletion, and searching

### Hashing

* Hash tables
* Hash functions
* Collision handling
* Hash-based searching and data storage

### Algorithms & Problem Solving

* Searching techniques
* Sorting concepts
* Traversal algorithms
* Insertion and deletion operations
* Algorithmic problem solving
* Time and space complexity analysis
